# DOCTRINE DIGIYLYFE — MAÎTRE, MASTER ET SIGNATURE

DIGIYLYFE industrialise la fabrication sans abandonner la décision humaine.

## 1. Le MAÎTRE décide

Le MAÎTRE fixe :

- la vision ;
- les règles ;
- les limites ;
- la qualité attendue ;
- les invariants de l’écosystème.

Aucune automatisation ne remplace cette autorité.

## 2. Le MASTER produit

Le MASTER transforme les informations du professionnel en présence numérique conforme aux standards DIGIYLYFE.

Il peut produire notamment :

- carte digitale ;
- fiche professionnelle ;
- site ;
- QR ;
- PWA ;
- support de présence territoriale.

Le MASTER industrialise ce qui doit être répétitif.

## 3. L’humain contrôle la finition

La production automatique n’est jamais considérée comme terminée sans contrôle humain.

L’humain vérifie notamment :

- le rendu visuel ;
- la lisibilité mobile ;
- le métier ;
- le territoire ;
- les formulations ;
- les photos ;
- les boutons ;
- les contacts ;
- le QR ;
- les détails culturels et locaux ;
- la cohérence générale.

L’œil humain garde la responsabilité de la finition.

## 4. DIGIYLYFE signe

Chaque production validée porte discrètement le logo DIGIYLYFE.

Le logo est :

- présent ;
- lisible ;
- plus petit que l’identité du professionnel ;
- positionné comme une signature ;
- jamais dominant.

Le professionnel reste au premier plan.

### Règle visuelle

**Identité principale : le professionnel.**  
**Signature secondaire : DIGIYLYFE.**

Le logo DIGIYLYFE signifie :

> Cette présence a été structurée selon les standards DIGIYLYFE.

Il ne remplace jamais l’identité du professionnel et ne transforme pas son support en publicité pour la plateforme.

## 5. Matière fournie au MASTER

Selon le support, les éléments variables peuvent comprendre :

- nom ;
- métier ;
- activité ;
- territoire ;
- téléphone ;
- WhatsApp ;
- photos ;
- logo du professionnel ;
- services ;
- tarifs ;
- langues ;
- couleurs ;
- médias ;
- liens ;
- QR.

Le MASTER applique ensuite la structure commune DIGIYLYFE.

## 6. Séquence de production

```text
INFORMATIONS DU PROFESSIONNEL
        ↓
MASTER DIGIYLYFE
        ↓
PRODUCTION
        ↓
CONTRÔLE HUMAIN
        ↓
CORRECTIONS DE FINITION
        ↓
VALIDATION DU MAÎTRE
        ↓
SIGNATURE DIGIYLYFE
        ↓
PUBLICATION
```

## 7. Règle de correction

Lorsqu’un défaut se répète, on ne corrige pas toutes les productions une par une.

**On corrige le MASTER à la source.**

Une correction structurelle doit améliorer toutes les productions suivantes.

Éviter les rustines répétées sur chaque carte, fiche ou site.

## 8. Doctrine technologique

DIGIYLYFE n’ajoute pas une technologie parce qu’elle est moderne.

Une technologie doit démontrer qu’elle rend le système :

- plus utile ;
- plus fiable ;
- plus simple ;
- plus autonome ;
- plus maîtrisable.

La machine fabrique ce qui peut être industrialisé.

L’humain conserve :

- le jugement ;
- le goût ;
- le contexte ;
- la décision ;
- la responsabilité finale.

## 9. Relation avec le professionnel

Le professionnel reste maître :

- de son activité ;
- de son identité ;
- de ses informations ;
- de son contact ;
- de sa relation avec ses clients.

DIGIYLYFE structure sa présence sans confisquer sa relation humaine.

## 10. Formule de référence

**Le MASTER produit.**  
**Le MAÎTRE valide.**  
**L’humain apporte la finition.**  
**DIGIYLYFE signe.**

## 10 bis. Règle d’accès propriétaire et e-mail

L’e-mail n’est pas une donnée obligatoire de la Carte digitale.

La Carte digitale :

- n’ouvre pas d’accès propriétaire par magic-link ;
- ne demande donc pas d’e-mail pour sa création ;
- conserve le contact direct téléphone / WhatsApp comme contact principal.

La Fiche professionnelle et le Site professionnel ouvrent un accès propriétaire sécurisé.

Pour eux :

- l’e-mail client est obligatoire ;
- cet e-mail sert au magic-link d’accès propriétaire ;
- il est saisi une seule fois dans le dossier central ;
- un Site ajouté à une Fiche réutilise le même e-mail : aucune ressaisie ;
- aucun faux e-mail ne doit être inventé pour satisfaire une contrainte technique.

Règle de référence :

**Carte = sans e-mail obligatoire.**  
**Fiche = e-mail magic-link obligatoire.**  
**Site = e-mail magic-link obligatoire, réutilisé depuis le dossier central.**

## 11. Alignement du dossier d’adhésion

La fiche d’adhésion est la porte d’entrée de la matière professionnelle.

Elle collecte une seule fois les informations utiles du professionnel :

- identité ;
- métier / activité ;
- territoire ;
- téléphone ;
- WhatsApp ;
- photo ;
- services ;
- besoins de présence ;
- prestation souhaitée.

Une information saisie une fois ne doit pas être redemandée plus loin.

Le parcours de référence est :

```text
ADHÉSION
    ↓
DOSSIER UNIQUE
    ↓
CHOIX HUMAIN DU MASTER
    ↓
MAÎTRE : CONTRÔLE DES INVARIANTS
    ↓
MASTER : PRODUCTION
    ↓
CARTE / FICHE / SITE
    ↓
CONTRÔLE ET FINITION HUMAINE
    ↓
VALIDATION
    ↓
SIGNATURE DIGIYLYFE
    ↓
PUBLICATION
```

Le choix du MASTER reste humain. Le système ne devine pas automatiquement le métier.

Carte, Fiche et futur Site doivent réutiliser le même dossier central et la même source de données.

La fiche d’adhésion collecte.  
Le MAÎTRE contrôle.  
Le MASTER produit.  
L’humain apporte la finition.  
DIGIYLYFE signe.

## 11. Principe final

**Industrialiser la fabrication.  
Préserver le jugement humain.  
Garder le professionnel maître de son activité et de son contact.**
